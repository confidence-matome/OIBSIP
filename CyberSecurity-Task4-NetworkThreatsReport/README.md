# OASIS Infobyte Security Analyst Internship – Task 4

## Common Network Security Threats

### Objective

The objective of this task was to research common network security threats, explain how they work, examine their real-world impact, and identify practical security measures that network administrators can use to reduce risk.

### Threats Covered

This report covers:

* **DoS/DDoS** – Denial-of-Service and Distributed Denial-of-Service attacks
* **MITM** – Man-in-the-Middle attacks
* **IP Spoofing** – Forging the source IP address of network traffic
* **DNS Poisoning/Spoofing** – Manipulating DNS information to redirect users

### Report Contents

The research report includes:

* Explanation of each threat
* How each attack works
* Real-world examples
* Potential impact on organizations
* Three specific mitigation strategies for each threat
* Comparison table of the threats
* Key takeaways for network administrators
* Credible security references
